# 网易云发现与飞牛本地画像使用说明

适用于 [Surc/fnos_music_ext](https://github.com/Surc/fnos_music_ext) v2.7.1。安装见 [INSTALL.md](INSTALL.md)，首页见 [README](../README.md)。

## 在管理页开启

1. 安装本版 FPK，选择网易云 musicbox；已有其他音源可在「音乐源」切换。
2. 用飞牛管理员打开「fnMusic 扩展管理」，在「音乐源」完成网易云扫码登录。
3. 在「播放与推荐」开启「每日推荐」和「结合我的飞牛历史和收藏」。
4. 同页「网易云发现」开启「显示发现歌单」，勾选类别，设置分类和数量。
5. 用「歌单分类顺序」的「上移 / 下移」调整顺序，点击「保存并生效」。
6. 回到飞牛音乐刷新。首次请求会后台抓取，稍后刷新可看到结果。

新安装默认开启发现与本地画像，六类全选、分类「华语」、每类八个、预热时间 04:30。已有 `.env` 保留自定义值；只拉取源码、没有执行升级安装时，新开关键可能缺失，应在管理页开启并保存。

## 六类发现内容

| 管理页名称 | 配置标识 | 内容 | 需要网易云登录 |
| --- | --- | --- | --- |
| 我的及收藏歌单 | `mine` | 自己创建的歌单和订阅的他人歌单 | 是 |
| 为你推荐歌单 | `nrec` | 当前网易账号的推荐歌单 | 是 |
| 排行榜 | `toplist` | 网易云榜单 | 否，曲目可播权限仍受账号影响 |
| 分类歌单 | `category` | 按华语、怀旧、流行等分类浏览 | 否，曲目可播权限仍受账号影响 |
| 新碟上架 | `newalbum` | 新专辑及其曲目 | 否，曲目可播权限仍受账号影响 |
| 私人 FM | `fm` | 当前网易账号的 FM 候选，以一个歌单快照展示 | 是 |

这些歌单显示在飞牛音乐原生列表，不需要另开播放器。均为只读，在飞牛里加歌、移歌、删歌不会改动网易云。曲目经可播过滤，实际数量可能小于云端歌单总数。

「音乐源」页保留原工程的「网易账号歌单」开关，只显示自建歌单。本版建议使用 `mine`；启用它时不会重复注入旧列表。取消 `mine` 或关闭发现后，旧开关仍可单独使用。

## 两种个性化的范围

| 内容 | 候选来源 | 按谁的记录处理 |
| --- | --- | --- |
| 飞牛「每日推荐 MM-DD」 | 偏好歌手、网易日推、可选 AI、本地曲库兜底 | 当前飞牛用户自己的历史与收藏 |
| 为你推荐歌单、私人 FM | 网易云原生接口 | NAS 上当前扫码登录的网易云账号 |
| 热门推荐、排行榜、分类、新碟 | 榜单或公共内容 | 保留对应内容，不套用本地画像重排 |

例如 A 常听周杰伦、B 常听爵士，他们的每日推荐分别按各自记录筛选和排序；NAS 登录同一个网易云账号时，网易推荐歌单与 FM 候选仍共享。每日推荐也不保证两人的曲目完全没有重合。

本版没有实现每个飞牛用户分别绑定网易云账号，也不把飞牛播放事件或收藏写回网易云训练云端画像。切换 musicdl / 洛雪后，网易云发现隐藏；每日推荐仍可结合个人历史、已配置的 AI 与本地曲库使用。

## 本地画像的生成与更新

- 本地音乐：只读官方数据库中当前用户的播放次数、时间和收藏。
- 在线音乐：读取扩展按用户保存的历史与收藏，包含次数和最近时间。
- 权重：收藏高于一次播放，重复播放增加权重，旧历史按约 30 天的时间尺度衰减。
- 网易云候选：先尝试最偏好的两位歌手，最多加入五首可播曲目，再接入网易日推及补充。
- 排序：排除当前用户近期历史 / 收藏中的歌曲，按偏好排序、惩罚歌手重复；有画像时每四个位置尝试保留一个探索位置。候选不足时多样性受曲库限制。
- 多用户：开启画像后，所有飞牛用户都能使用网易日推候选，各自排除和排序，不再只有当天首个用户使用网易候选。

关闭「结合我的飞牛历史和收藏」回到原工程每日推荐流程，包括网易日推首个用户名额规则；关闭「每日推荐」隐藏该歌单。发现类别有独立开关。

## AI 补充

AI 为可选项，没有模型也能使用网易云发现与画像。配置有效的 `FNMUSIC_LLM_*` 后，画像模式给 AI 留出补充位置；保留歌曲搜索匹配和可播校验，无法解析的候选不会直接显示为可播歌曲。

开启 AI 时，向你配置的 OpenAI 兼容 API 发送推荐提示词，包含历史和收藏中的种子曲目元数据；网易云 Cookie 不作为 AI 推荐输入。这个过程不会向网易云写回听歌记录。

## 缓存和顺序

| 内容 | 默认策略 |
| --- | --- |
| 发现摘要 | 五分钟；有旧缓存先显示，后台更新 |
| 普通歌单 / 专辑曲目 | 六小时；默认最多获取 300 首 |
| 私人 FM 曲目 | 固定五分钟，以歌单快照展示，并非连续广播流 |
| 每日推荐 | 六小时或跨日重建；画像变化时至少间隔半小时，访问时后台触发 |
| 每日预热 | NAS 本地时间 04:30；留空关闭定时预热，访问刷新仍生效 |
| 网络失败 | 保留已有缓存，暂停重试一分钟；旧发现缓存最多七天 |

私人内容按网易账号隔离缓存，未登录时隐藏。账号状态有短暂缓存，登录或切换账号后可稍等再刷新。

分类顺序包括每日推荐、热门推荐与六类发现。高级用户可设置 `FNMUSIC_NETEASE_PLAYLIST_ORDER` 指定单个歌单优先级，填 `daily` / `hot` 或 GUID；普通歌单形如 `online:playlist:ne:123456`，专辑 `online:playlist:nealbum:123456`，FM `online:playlist:nefm:<网易账号ID>`。

完整配置见 [首页配置表](../README.md#新功能配置参考) 和 [.env.example](../.env.example)。

## 排查没有内容

1. 六类都没有：确认本集成版、网易音源和发现总开关已启用，首次抓取后刷新。
2. 公共内容有、私人内容没有：检查网易云扫码登录是否有效。
3. 曲目很少：检查账号权益、版权与 URL 解析，可播过滤会减少条目。
4. 刚收藏推荐没变：半小时冷却和六小时缓存避免频繁重建，并非每次切歌都重算。
5. 没有新设置：确认升级及容器重建完成，并刷新管理页，见 [INSTALL.md](INSTALL.md)。

实际验证范围见 [VALIDATION.md](VALIDATION.md)。自动测试使用真实结构与模拟响应；fnOS 实机安装、升级、卸载和真实账号播放仍需实际设备验收。
