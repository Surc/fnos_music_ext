# 网易云下载跨平台补源

v2.8.0 新增，默认关闭。v2.7.1 Release 不包含此功能。补源基于本仓库已有 musicdl 接口独立实现，两来源的采用版本仍为 javycoder v2.7.0、gzywd v2.9.30；本次没有推进上游基线。

## 开启和选择保存位置

1. 管理页「音乐源」选择网易云 musicbox，按需要扫码登录。
2. 在「边听边存」开启「网易下载跨平台补源」，填写备用平台顺序，例如 `kuwo,migu,kugou,qq`。支持这四个平台，按填写顺序尝试，默认 `kuwo,migu`。
3. 目标选「无损编码格式」或「320 kbps 或更高」。默认无损、严格模式；没有满足目标的完整资源就失败。开启「允许降级」后，平台都未达标时可保留验证合格的较低音质；仍不接受试听或不匹配的歌曲。
4. 设置该页原有「保存路径」，点「保存并生效」。这是 NAS 文件系统目录，供本机所有用户共用；不是音乐库下拉选择。留空时优先现有官方共享音乐库目录，否则使用扩展缓存目录。手动下载会先准备完整文件，边听边存需开启原有保存开关。

保存到官方已扫描的目录后，按原有流程触发曲库扫描和各请求用户自己的收藏 / 歌单绑定。保存文件可以共享；用户身份、收藏和历史沿用原有隔离机制。新选项只适用于网易主音源，切换 musicdl / lxmusic 后不使用下载补源。

## 一首歌如何下载

- 优先复用已保存、通过完整校验且满足目标的文件；否则重新从网易取整轨。旧低档缓存不阻止重新检查网易当前权益和可下载音质。
- 网易无 URL、只有短试听、文件不完整 / 损坏，或实际编码 / 音频码率未达到目标时，按配置的平台顺序搜索同曲。
- 搜索结果和 `/info` 元数据都要通过歌名、全部署名歌手、版本标记和时长检查；候选完整下载后再检查真实编码、时长和全量解码。每个平台最多考察三个匹配候选，首个满足目标的结果优先。
- 所有候选都不合格时，严格模式返回失败；允许降级时选择已验证完整、版本匹配的最佳可用音频。失败不删除原有低音质曲库文件，严格模式不会把它作为下载成功返回。

标题采用 Unicode 规范化、大小写及标点归一化；歌手集合和 Live / 翻唱 / 伴奏 / Remix / 重制等版本标记必须相同。双方必须有已知时长，容差 2–4 秒（约时长的 1%）。证据不足则跳过，可能错过同名异写的正确资源。

无损目标按实际 FLAC / ALAC / PCM / WavPack 编码判断；320 kbps 档要求无损编码或至少 304 kbps 的音频流码率（容差 5%）。不使用文件后缀或包含封面的容器总码率代替音频检查。明确标注有损转码 / 升频的候选会被拒绝，但 ffprobe 不能证明平台母带从未经过有损处理，本版不承诺 Hi-Res 或原生无损鉴定。

## 来源记录和旧文件

新下载的音频旁有同名 `.fnmusic-source.json`，包含 `original_guid`、`provider`、`provider_track_id`、匹配字段、实际 codec / bitrate / sample_rate / duration、目标及是否达标、触发原因和时间。不含下载 URL、账号凭证或听歌画像。原始网易 GUID 继续用于歌词、收藏和播放记录，实际来源单独存放。

例如 `歌手 - 歌名.flac.fnmusic-source.json` 中 `provider=migu` 表示文件实际来自咪咕；`trigger=below_target` 表示网易音质不足触发补源。`original_lossless_verified=false` 明确表示没有证明原始母带为无损。

升级成功会按校验后的真实编码命名，并让 GUID 引用指向新文件的完整路径，避免同目录旧 MP3 遮住新 FLAC。不同扩展名的旧文件继续保留；同路径同格式升级使用原子替换。官方扫描可能展示两种版本，用户可按需要自行整理。已经存在的达标文件直接复用，旧版文件没有来源记录时不会猜测它的平台。

## 资源和配置

备用服务不改变主音源选择。仅在需要补源时启动独立进程，同曲请求共用下载任务；最多两个同时工作、八个排队任务。租约每 20 秒续期，60 秒未续期失效，最后一个租约结束后空闲约 30–35 秒停止进程。主音源 / 补源配置变化会取消旧任务、清除旧策略的失败冷却；临时 `.part` 文件清理，同一配置下载失败后按原有 30 分钟冷却抑制立即重试。

| 配置键 | 默认值 | 管理页含义 |
| --- | --- | --- |
| `FNMUSIC_DOWNLOAD_FALLBACK_ENABLED` | `false` | 开启网易下载补源 |
| `FNMUSIC_DOWNLOAD_FALLBACK_SOURCES` | `kuwo,migu` | 支持 `kuwo,migu,kugou,qq`，顺序即尝试顺序 |
| `FNMUSIC_DOWNLOAD_FALLBACK_TARGET` | `lossless` | `lossless` 无损编码，或 `320k` |
| `FNMUSIC_DOWNLOAD_FALLBACK_ALLOW_DOWNGRADE` | `false` | 全部未达标时是否交付完整低档资源 |
| `FNMUSIC_DOWNLOAD_FALLBACK_BUDGET_S` | `180` | 整个任务预算 30–600 秒，包含排队与启动 |
| `FNMUSIC_DOWNLOAD_FALLBACK_MAX_MB` | `150` | 每个候选最大 10–1024 MiB |

取消和超时后，正在执行的音频校验或原子提交会先完成清理，因此请求收尾可能略超任务预算。音频检测要求宿主机已有 `ffprobe` 和 `ffmpeg`；缺失时失败，不假装通过质量检测。

容器内部备用接口为 8006，宿主只映射 `127.0.0.1:8776`，控制 Socket 在共享数据目录 `sources-data/download-fallback.sock`（0600）。沿用容器运行用户，不挂 Docker Socket，不新增公开控制接口或绕过飞牛管理员网关。控制协议与实际容器验证见 `tests/integration/download_fallback_contract.py`。

## 首版边界和验收

此功能针对已有或可取得完整网易元数据的曲目，包括原已收藏但之后失效的 GUID。网易搜索 / 发现列表仍按账号权限过滤；被提前过滤的 VIP 曲目不会因打开此开关自动出现。若无法获得歌名、歌手或时长，也不能可靠地跨平台匹配。

在线播放先按原音源完成，不在同一次流式 / Range 请求中混入其他平台字节；边听边存完成原文件后可独立升级。原播放本身无法开始时，不能靠尚未发生的边听边存触发补源，应使用可用曲目的下载 / 后台整轨任务。App 的「标准」下载仍按原协议交付 MP3，目标约束作用在准备的源文件；需要保留 FLAC 时选 App 的「原始」下载。

不能保证每首歌在备用平台都有完整、同版本或目标音质资源。测试覆盖模拟 API、真实生成音频，完整 CI 和实际容器离线契约已通过；真实账号、fnOS 安装升级、手机 App 下载和官方扫描 / 绑定仍需实机验收。结果记录在 [VALIDATION.md](VALIDATION.md)。
